This Go application functions as an AI agent interacting with the Gemini API for code analysis. It offers capabilities like code review, documentation generation, and Q&A, dictated by command-line flags. The agent supports processing single files or aggregating content from entire directories, intelligently marking file boundaries. A "deep learning" mode maintains and utilizes conversation history for context-aware responses. Core functionalities include dynamic prompt building, robust file I/O for reading source code and writing AI output, and handling HTTP requests with JSON payload management. The system provides user feedback with a spinner and incorporates comprehensive error handling.
